# UCI Occupancy Detection

Fuente: UCI Machine Learning Repository, dataset 357.

URL: https://archive.ics.uci.edu/dataset/357/occupancy+detection

Archivos:

- `datatraining.txt`: particion de entrenamiento.
- `datatest.txt`: primera particion de test.
- `datatest2.txt`: segunda particion de test.
- `occupancy_detection.zip`: descarga original conservada.

Variables principales:

- `date`: marca temporal.
- `Temperature`: temperatura interior.
- `Humidity`: humedad relativa interior.
- `Light`: iluminancia.
- `CO2`: concentracion de CO2.
- `HumidityRatio`: ratio de humedad.
- `Occupancy`: etiqueta binaria de ocupacion.

Uso recomendado:

- Clasificacion supervisada de ocupacion.
- Practicas introductorias de sensores ambientales, balance de clases y validacion train/test.

Cita sugerida:

Luis Candanedo. Occupancy Detection. UCI Machine Learning Repository. https://doi.org/10.24432/C5X01N
